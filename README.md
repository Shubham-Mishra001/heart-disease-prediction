# Heart Disease Prediction App

## Overview

This project predicts the likelihood of heart disease using machine learning and provides an interactive web application using Streamlit. Users can input basic health parameters and receive real-time predictions.

---

## Features

Predict heart disease risk based on user input
Simple and user-friendly interface
Machine learning model using Random Forest
Real-time prediction through web app

---

## Dataset

Source: UCI Heart Disease Dataset
Total Records: approximately 1000+
Selected Features include Age, Gender, Chest Pain Type, Resting Blood Pressure, Cholesterol, Max Heart Rate, and ST Depression

---

## Machine Learning Model

Algorithm used is Random Forest Classifier
It is chosen because it handles non-linear relationships and improves prediction accuracy
Feature selection is applied for better usability and performance

---

## Project Workflow

Data loading and understanding
Data cleaning and preprocessing
Exploratory data analysis
Feature selection
Model training and evaluation
Deployment using Streamlit

---

## Results

The system provides real-time prediction of heart disease risk
Prediction reliability is improved using Random Forest
